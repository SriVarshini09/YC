# SHAPI brand assets

The logo is "Shape + Pulse": a navy rounded square (`#0B1F4D`), a white hexagon outline (the shape of an API), and inside it a pulse line that glitches and ends in a check, with a gradient from electric blue (`#2F6BFF`) to mint (`#19D3A2`). The wordmark is "shapi" in Space Grotesk SemiBold, converted to outlines.

| File | Use |
| --- | --- |
| `shapi-icon.svg`, `shapi-icon-512.png`, `shapi-icon-256.png` | The icon. The 512px PNG is the GitHub App avatar (upload it under the app's settings on GitHub). |
| `shapi-logo-light.svg` / `.png` | Full logo for light backgrounds (navy wordmark). |
| `shapi-logo-dark.svg` / `.png` | Full logo for dark backgrounds (white wordmark). |
| `shapi-mark.svg` | The hexagon and pulse without the tile, for navy backgrounds. |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | Favicons. The 16 to 32px version is pulse-only, without the hexagon. |
| `shapi-social.png` / `.svg` | Social share image, 1200 x 630. |

Everything is generated by `generate.mjs`, which also refreshes the copies in `site/public/` (docs site) and `apps/server/src/web/brand.ts` (web app). To change the design, edit the script and run:

```sh
cd brand && npm install && npm run generate
```

This folder is deliberately outside the pnpm workspace so its rendering dependencies are not installed with the rest of the repository.
