# M5-T3 YC application draft

What exists: `research/06-yc-application.md`, a draft answer to each YC application question, built on what exists and was verified. That covers the shapi-demo fix PR with CI green, the live canaries, the live Claude fallback and editor runs, the observatory (70% of 50 APIs contradict their spec, 24% of endpoints match), and commit mining (median 203 days to fix GitHub's silent change and 343 days for QuickBooks', both hand-verified). `research/07-demo-script.md` is a shot-by-shot script for the 60–90 second demo video.
How to run: edit the draft. The 12 `⟦FILL⟧` markers need founder-only facts: names and backgrounds, location, time spent, users, revenue, pricing decision, other ideas, demo video link, domain or repo link.
Not done: the demo video (the founders record it); publishing `shapi` to npm so the application can link a product anyone can run.
Decisions: claims are limited to what was built or measured. The thesis line about customers' traffic catching the change is kept out, and a "Claims to keep straight" section lists the wordings to use. The pricing model is a proposal marked for the founders to decide.
